# ui-kit-one → Chakra UI v1 mapping

> Generated by `pnpm build` (`pnpm run docs`) from the component mappings. Do not edit by hand.

Contract prop names and values equal the kit's wherever a prop is plain data (DEC-005), so most props are **identity**: passed through unchanged, kit defaults apply when omitted. Only translated props are declared by hand.

- Passthrough components (one registry line each): `Box`, `Center`, `Container`, `Flex`, `Grid`, `Heading`, `Text`, `Tag`, `Avatar`.
- Custom components hold their implementation and mapping in one file. To remap a component, edit that file (and its facade in `src/kit/` when the kit API differs), then run `pnpm build`.
